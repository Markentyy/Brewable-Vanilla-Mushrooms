### Added

- Keg juice for all vanilla mushrooms via `keg_juice` context tag:
  Morel (257), Chanterelle (281), Common Mushroom (404),
  Red Mushroom (420), Purple Mushroom (422), Truffle (430), Magma Cap (851).
- `TargetField` edits so existing `ContextTags` from the game and other mods are preserved.
